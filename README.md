# Telegram 2GB Direct Link Downloader Bot (Super God Tier - Level 1000+) ⚡👑

أقوى بوت تليجرام لتحميل الروابط المباشرة وتحويل الروابط غير المباشرة أوتوماتيكياً (Google Drive, GitHub, Dropbox) حتى **2 جيجابايت** ورفعها على تليجرام بسرعة فائقة ومزود بسجل ملفات شخصي لكل مستخدم ولوحة تحكم مسؤول وإذاعة عامة.

---

## ⚡ الميزات الأسطورية الفائقة (Level 1000+)

1. **المحول الذكي للروابط (Auto Link Converter)**:
   - تحويل أوتوماتيكي لروابط **Google Drive** المشاركة إلى روابط تنزيل مباشرة.
   - تحويل روابط **GitHub Blob** إلى `raw.githubusercontent.com`.
   - تعديل روابط **Dropbox** إلى التنزيل المباشر المباشر `dl=1`.

2. **سجل الملفات الشخصي لكل مستخدم (`/history`)**:
   - توثيق أحدث 10 ملفات قام كل مستخدم بتحميلها (مع اسمها، حجمها، وتاريخ التحميل) ويمكن استعراضها بزر `[ 📜 ملفاتي الأخيرة ]` أو بالأمر `/history`.

3. **شارات السرعة الحركية (Dynamic Speedometer Badges)**:
   - شارات سرعة تفاعلية لايف:
     - `⚡ [سرعة نارية خارقة 🔥]` عند تجاوز 10 MB/s.
     - `🚀 [سرعة عالية جداً ⚡]` عند تجاوز 3 MB/s.
     - `✈️ [سرعة ممتازة]` عند تجاوز 1 MB/s.

4. **لوحة تحكم المسؤول والإذاعة العامة (Admin Panel & Broadcast)**:
   - دعم التعيين الاختياري لـ `ADMIN_ID`.
   - زر خاص بالمالك `[ 👑 لوحة المسؤول ]`.
   - أمر الإذاعة العامة لكل مستخدمين البوت: `/broadcast نص الرسالة`.

5. **زر الإلغاء اللحظي المباشر (`[ 🛑 إلغاء هذه العملية فوراً ]`)**:
   - إلغاء فوري للتحميل أو الرفع وتفريغ مساحة السيرفر فوراً بنقرة زر.

6. **دعم إرسال روابط متعددة دفعة واحدة (Bulk Multi-Links)**:
   - إرسال عدة روابط في رسالة واحدة (كل سطر رابط) مع خيارات الاسم والكابشن المخصص لكل منها.

---

## 💻 التشغيل المحلي (Local Setup)

```cmd
pip install -r requirements.txt
python bot.py
```

---

## 🌐 النشر على Render

- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python bot.py`
- قم بتعيين `API_ID`, `API_HASH`, `BOT_TOKEN`, و `ADMIN_ID` (اختياري) في إعدادات Render.
